# XYZBOOK

Open-source prediction market protocol.

## Overview

XYZBOOK is a modular prediction market protocol designed for transparent, fair and verifiable markets.

## Core Features

- Sports prediction markets
- YES/NO markets
- Market creation
- Order matching
- Positions
- Settlement
- Oracle-based outcomes
- Wallet integration
- Multi-chain support
- Community-built frontends

## Principles

- Transparency
- Fairness
- Security
- Verifiable outcomes
- Non-custodial architecture
- Open-source development
- Scalable infrastructure
